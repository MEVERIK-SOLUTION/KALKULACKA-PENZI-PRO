# **UI Katalog: KALKULAČKA PENZÍ PRO**

Verze: 1.0 | Status: Finální pro uložení do repozitáře

## **1\. Barevná paleta (Color Design System)**

Základní barvy definující vizuální identitu aplikace. Jsou vybrány pro maximální čitelnost a pocit důvěryhodnosti ve finančním segmentu.

| Role barvy | Název | HEX kód | Použití |
| :---- | :---- | :---- | :---- |
| **Primární** | **Navy Blue** | \#1A2B48 | Záhlaví, navigace, hlavní nadpisy, pozadí expertních grafů. |
| **Sekundární** | **Emerald Green** | \#2ECC71 | Potvrzující akce (CTA), pozitivní finanční bilance, progress bary. |
| **Akcentní** | **Amber** | \#F59E0B | Upozornění na chybějící data, varování, zvýraznění mezer v pojištění. |
| **Neutrální** | Light Grey | \#F8F9FA | Celkové pozadí aplikace. |
| **Povrchy** | Pure White | \#FFFFFF | Karty modulů, formulářová pole. |

## **2\. Typografie**

Kombinace moderního bezpatkového písma pro rozhraní a neproporcionálního písma pro precizní práci s čísly.

### **UI Font: Inter / Roboto**

* **H1 (Nadpisy sekcí):** Bold, 24px, barva Navy Blue.  
* **Body Text (Instrukce):** Regular, 16px, barva Tmavě šedá (\#333333).  
* **Labels (Popisky polí):** Semi-bold, 14px, barva Grey (\#666666).

### **Data Font: JetBrains Mono / Roboto Mono**

* **Finanční částky:** Medium, 16px. Zajišťuje, že tisíce a stovky lícují v tabulkovém zobrazení pod sebou.  
* **Data a kódy:** Regular, 14px. Pro výpisy dob pojištění (např. 01.01.1990 \- 31.12.1995).

## **3\. Ikonografie**

Styl: **Modern Line-Art**. Ikony využívají tloušťku tahu 2px se zaoblenými konci. Hlavní barva Navy Blue, drobné akcenty v Emerald Green.

| Prvek | Vizuální metafora |
| :---- | :---- |
| **Digitální Trezor** | Symbol bezpečí pro nahrávání IOLDP dokumentů. |
| **Státní Složka** | Oficiální záznamy z ČSSZ. |
| **Optimalizační Lupa** | Hledání mezer v historii pojištění (Amber akcent). |
| **AI Radar** | Inteligentní notifikace na legislativní změny. |
